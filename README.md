# época — Everything at a glance

época is a personal workspace for keeping tasks, notes, and a clear view of today together. This repository contains a React/Vite client and an Express/MongoDB API. The app opens directly in a browser-specific guest workspace; signing in is not required.

## MVP included

- Guest workspace with task CRUD, status and priority, due dates, search, and three-column Kanban.
- Notes CRUD, search across title and content, and pinning.
- Dashboard counts, due/overdue tasks, recently updated notes, quick capture, and recent activity.
- Responsive workspace navigation and explicit loading, empty, and error states.

Journal, projects, and calendar are marked as later work and do not show placeholder data.

## Requirements

- Node.js 20.19+ and npm.
- MongoDB Community Server locally, or a MongoDB connection string.

## Run locally

1. Install dependencies:

   ```sh
   npm install
   ```

2. Copy `.env.example` to `.env` and set `MONGODB_URI`. Keep `.env` private; it is ignored by Git. `JWT_SECRET` is only needed if you use the optional legacy account endpoints.

3. Start MongoDB, then run both apps:

   ```sh
   npm run dev:all
   ```

   The Vite client is available at `http://127.0.0.1:5173`; the API listens on `http://127.0.0.1:4000`.

   Alternatively, run `npm run dev` and `npm run server` in separate terminals.

4. Open the app and start using the workspace. Task and note data is stored in MongoDB and scoped by a random workspace id saved in this browser's local storage. Clearing browser storage creates a new workspace.

Guest workspaces are not authenticated or suitable for sensitive data: anyone who obtains a workspace id can access that workspace. Use the optional account endpoints only if you configure a private deployment and a strong `JWT_SECRET`.

## Environment variables

| Variable | Purpose |
| --- | --- |
| `MONGODB_URI` | MongoDB database connection string; required by the API. |
| `JWT_SECRET` | Optional secret for the legacy account endpoints; use at least 32 random characters if enabled. |
| `PORT` | API port; defaults to `4000`. |
| `FRONTEND_URL` | Exact client origin allowed by CORS; defaults to `http://localhost:5173`. |
| `NODE_ENV` | Set to `production` to enable the secure session cookie flag. |
| `VITE_API_URL` | Public API base URL for the client; defaults to `http://localhost:4000/api/v1`. |

Account sessions use an `HttpOnly`, `SameSite=Lax` cookie. Guest workspace functionality does not use authentication cookies. Use HTTPS in production.

## API

All endpoints use the `/api/v1` prefix and return a consistent `{ error: { code, message } }` shape for failures.

| Method | Endpoint | Purpose |
| --- | --- | --- |
| `POST` | `/auth/register` | Create an account and start a session. |
| `POST` | `/auth/login` | Start a session. |
| `POST` | `/auth/logout` | Clear the session cookie. |
| `GET` | `/auth/me` | Get the current account. |
| `GET`, `POST` | `/tasks` | List (optional `status`, `priority`, `search`) or create tasks. |
| `GET`, `PATCH`, `DELETE` | `/tasks/:id` | Read, update, or delete an owned task. |
| `GET`, `POST` | `/notes` | Search/list (`search`, `tag`) or create notes. |
| `GET`, `PATCH`, `DELETE` | `/notes/:id` | Read, update, or delete an owned note. |
| `GET` | `/dashboard/summary` | Get database-backed counts and recent items. |
| `GET` | `/activity-logs` | Get recent activity for the current account. |

Task list filters include `status`, `priority`, and `search`; note `search` checks title and content. Task and note routes use the `X-Workspace-Id` header generated by the client and scope records to that browser workspace. This id is not an authentication credential; guest workspace data is not private. Password hashes are excluded from normal user queries and are never included in responses.

## Verification

```sh
npm run build
npm run lint
```

`npm run build` type-checks both the client and server, then builds the client. For manual end-to-end verification, use a running MongoDB instance, create a task and note without signing in, then reload and confirm they remain in the same browser workspace.
